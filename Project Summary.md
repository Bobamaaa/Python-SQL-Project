# Python-SQL-Project

In this project, I conducted an end-to-end data analysis of sales records to uncover key business insights. The process began with data cleaning and preprocessing using Python (Pandas), where I handled missing ##values, standardized column formats, and ensured overall data consistency. Once cleaned, I imported the dataset into SQL Server to perform Exploratory Data Analysis (EDA).

Using SQL, I answered a wide range of business-critical questions related to sales performance, profitability, customer segments, shipping efficiency, seasonal trends, and product-level analysis. The queries were designed to support strategic decision-making—identifying high-performing regions, underperforming product categories, optimal discount levels, and opportunities for cost optimization.

This approach provided actionable insights that can help stakeholders improve marketing strategies, streamline operations, and enhance profitability.
